02 / Working method

From practical to proof

A clear process makes each lab easier to review, reproduce, and learn from.

STEP 01Define

Set the objective, environment, authorisation, and boundaries.

STEP 02Investigate

Run the practical and record commands, versions, and observations.

STEP 03Validate

Compare claims with actual output and note limitations or uncertainty.

STEP 04Document

Add sanitised evidence, explain the result, and capture lessons learned.

03 / Quality & responsibility

Standards that matter

Technical integrity

  • Only report results that were actually observed.
  • Keep expected values separate from verified configuration.
  • Document failed attempts and limitations honestly.
  • Make methods understandable and repeatable.

Responsible practice

  • Test only systems owned by you or explicitly authorised.
  • Remove secrets, personal details, and unnecessary identifiers.
  • Keep sensitive packet captures and VM images out of Git.
  • Follow the repository's security guidance.
