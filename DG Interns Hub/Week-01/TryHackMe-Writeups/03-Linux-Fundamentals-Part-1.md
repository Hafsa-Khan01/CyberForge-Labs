# TryHackMe Write-up — Linux Fundamentals Part 1

## Objective
Become comfortable navigating a Linux terminal and inspecting files and directories.

## Core Commands
- `pwd`: print current working directory.
- `ls -la`: list visible and hidden entries with details.
- `cd`: change directory.
- `cat` / `less`: read file contents.
- `mkdir` / `touch`: create directories and files.
- `cp` / `mv`: copy and move or rename.
- `man <command>`: read command documentation.

## Approach
Read the task carefully, identify the required file or directory, inspect the current path, then run the smallest appropriate command. Verify the result with a follow-up listing or file read.

## Learning Reflection
Linux commands are composable; understanding paths, permissions and command help is more valuable than memorizing isolated commands.
