# TryHackMe Write-up — Search Skills

## Objective
Develop a repeatable method for finding reliable technical information using search engines and primary documentation.

## Method
1. Convert the question into specific technical keywords.
2. Search exact error messages in quotation marks.
3. Narrow results by product, version, operating system or domain.
4. Prefer official documentation, vendor advisories and reputable technical references.
5. Compare more than one source and check publication/update dates.
6. Record the query, source, relevant finding and confidence.

## Key Learning
Search quality improves when a broad question is split into smaller verifiable questions. Search results are leads, not proof; validate claims against primary sources.
