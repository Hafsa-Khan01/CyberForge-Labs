# TryHackMe Write-up — Introductory Networking

## Objective
Learn foundational network addressing, common protocols and ports.

## Concepts
- IPv4 addresses identify interfaces logically.
- Subnet masks/prefixes define network boundaries.
- A default gateway forwards traffic to other networks.
- TCP provides connection-oriented transport; UDP is connectionless.
- DNS commonly uses port 53; HTTP 80; HTTPS 443; SSH 22; SMB 445.

## Approach
Read addressing information carefully, distinguish host and network portions, and identify the service associated with a port before interpreting traffic.

## Learning Reflection
A port number suggests a service but does not prove which application is running; verify with authorized service identification.
