# TryHackMe Write-up — Intro to LAN

## Objective
Understand local area networks, switching, addressing and basic segmentation.

## Concepts
A LAN connects devices within a limited area. Ethernet switches learn source MAC addresses and forward frames accordingly. VLANs can separate logical broadcast domains. A router or Layer 3 switch enables communication between IP networks when configured to do so.

## Security Considerations
Use segmentation, secure switch management, port security where appropriate, and monitoring for unexpected devices or ARP behaviour.

## Learning Reflection
A LAN is not automatically trusted; internal access should still follow least privilege and monitoring.
