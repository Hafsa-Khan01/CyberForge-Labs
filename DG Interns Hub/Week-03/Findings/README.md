# Practical Evidence Index

Store original screenshots from actual lab sessions. Do not use stock imagery, recreated terminal output, fabricated alerts or invented timestamps.

## Suggested folders
- Windows-Sysmon — service/channel verification and Event IDs 1, 3, 11, 13 and 22.
- Ubuntu-auditd — service status, ausearch output and correlated audit records.
- Ubuntu-Snort — version/configuration validation and live alerts.
- Kali-Nmap — authorized SYN scan output.
- TryHackMe — room completion evidence where platform rules permit.
- LetsDefend — course completion evidence where platform rules permit.

## Screenshot standards
Keep original captures, use descriptive filenames, include enough context to interpret the event, and redact personal identifiers, tokens, public IPs and unrelated sensitive details before public sharing.
