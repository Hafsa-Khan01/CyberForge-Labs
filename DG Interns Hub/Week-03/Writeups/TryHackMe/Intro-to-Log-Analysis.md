# TryHackMe — Intro to Log Analysis

**Room:** https://tryhackme.com/room/introtologanalysis

## Objective
Practice examining logs, filtering relevant records, recognizing suspicious patterns and supporting conclusions with context.

## Triage workflow
1. Define the investigation question.
2. Set a time window and normalize timezone.
3. Filter by host, account, process, event type or network indicator.
4. Group related events and build a timeline.
5. Compare activity with expected behavior.
6. Record evidence, uncertainty and next steps.

## SOC analysis
Explain why the records were relevant, what additional telemetry would strengthen the finding, and why one log line rarely proves malicious intent.
