# LetsDefend — Network Log Analysis

**Location:** SOC Analyst Learning Path

## Learning focus
Analyze network telemetry to understand communications, identify suspicious patterns and correlate network activity with endpoint and identity events.

## Core fields
Timestamp, sensor, protocol, source/destination IP and port, direction, action, bytes/packets, connection state, DNS/HTTP metadata and enriched host/user/process context.
