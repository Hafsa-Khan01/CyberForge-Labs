# TryHackMe — Splunk: Exploring SPL

**Room:** https://tryhackme.com/room/splunkexploringspl  
**Completion status:** Completed

## Learning outcomes
- Use SPL to search and filter indexed events.
- Transform results with commands such as `where`, `stats`, `table`, `eval`, `timechart` and `rex`.
- Aggregate events and identify patterns relevant to security investigations.
- Validate fields, time ranges and data sources before relying on search results.

## Practical relevance
SPL supports investigation by narrowing event datasets, extracting useful fields and summarising activity. A search returning no results does not automatically mean the activity did not occur; index selection, time range, sourcetype and field extraction must also be checked.
