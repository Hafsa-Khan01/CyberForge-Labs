# TryHackMe Write-up — Windows Fundamentals 1

## Objective
Understand the Windows interface, file system, system configuration and basic security features.

## Topics
Review the Windows desktop, file explorer, user account concepts, system configuration tools, Task Manager, UAC and Windows Defender / built-in security features as presented in the lab.

## Method
Navigate the training VM, inspect the named tools and settings, and write down their purpose. Distinguish standard-user actions from actions requiring administrator privileges.

## Learning Reflection
Knowing where Windows exposes system and security information makes later event-log and endpoint investigations more effective.
