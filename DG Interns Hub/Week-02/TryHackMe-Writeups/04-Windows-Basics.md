# TryHackMe Write-up — Windows Basics

## Objective
Become familiar with Windows desktop administration and common system-management areas.

## Topics
Explore the desktop and file system, Settings and Control Panel, Task Manager, local users and groups, services, system information and basic security controls. Understand the role of User Account Control (UAC) in requesting elevation for administrative actions.

## Method
Use the provided training environment, inspect each feature requested by the room, and record what it does. Avoid changing settings outside the exercise requirements.

## Learning Reflection
Windows security investigations often begin with understanding normal processes, services, accounts and administrative boundaries.
