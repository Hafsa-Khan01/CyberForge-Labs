# TryHackMe Write-up — Windows Fundamentals 2

## Objective
Understand Windows system utilities and management interfaces used during administration and troubleshooting.

## Topics
Study the utilities covered in the room, their purpose, and how they expose system configuration or diagnostic information. Relate the tools to processes, services, storage, networking and system management.

## Method
Use the room's Windows environment, open each requested utility, note the information it provides and avoid making unrequested system changes.

## Learning Reflection
A Windows analyst should know which built-in utility can answer a question, what privileges it requires and how to preserve relevant observations.
