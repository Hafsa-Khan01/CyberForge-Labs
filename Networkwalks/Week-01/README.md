## Evidence integrity

The [evidence index](EVIDENCE-INDEX.md) is the source of truth for the curated 41-screenshot Week 01 submission set and its folder breakdown. Result-card scores are reported as learner-recorded assessment outcomes; they are not presented as independent packet-capture verification.

Before sharing, review screenshots for credentials, personal data, host usernames, local paths, MAC addresses and unrelated network details. Never publish VM disks, saved states, private keys or unreviewed PCAP files.
