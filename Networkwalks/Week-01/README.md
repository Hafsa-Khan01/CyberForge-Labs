## Evidence integrity

The [evidence index](EVIDENCE-INDEX.md) distinguishes the original 46-image source package from the files currently published in this repository. Result-card scores are reported as learner-recorded assessment outcomes. They are not presented as independent packet-capture verification.

Before sharing, review screenshots for credentials, personal data, host usernames, local paths, MAC addresses and unrelated network details. Never publish VM disks, saved states, private keys or unreviewed PCAP files.
