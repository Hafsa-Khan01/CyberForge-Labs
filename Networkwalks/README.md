## Evidence handling

The original evidence package includes VM setup and Wireshark practical screenshots. Screenshots must be reviewed for credentials, personal information, and sensitive network details before public upload. Never commit VM disk images, saved-state files, private keys, or unreviewed PCAPs.

## Reporting

Document only completed work and distinguish learner-supplied results from independently verified packet analysis.
