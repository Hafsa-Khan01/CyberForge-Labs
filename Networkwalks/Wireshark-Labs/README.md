# Wireshark Labs

Use one report per assigned lab. Only document captures collected for the exercise and avoid capturing unrelated personal traffic.

## Suggested report fields
- Lab number and assigned URL
- Objective
- Capture setup and interface
- Display filter used
- Observed packet/protocol fields
- What the observation demonstrates
- Screenshot filename
- Conclusion and questions

## Display filter quick reference
`dns` · `tls` · `tcp` · `icmp` · `ip.addr == <authorized-lab-ip>`

Replace the example address with the address authorized for the specific lab. Do not include raw packet captures unless explicitly permitted and reviewed for private data.
