## Safe analysis reminders

- Use only the assigned training capture or an authorised lab network.
- Avoid publishing credentials or personal data recovered from packet payloads.
- Prefer TLS/HTTPS, secure FTP alternatives, and SRTP for production communications.
- Keep raw PCAP files private unless explicitly approved for publication.
