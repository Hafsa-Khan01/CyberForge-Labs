## Scope and privacy

The Zenmap exercise was a Ping Scan of the tester's own local Wi-Fi subnet. Local host addresses and the router MAC address are redacted in this public-facing documentation. The scan did not enumerate ports or services.

The official PM4 target was `microsoft.com`. The theHarvester exercise was attempted, but a source-side server error/disconnection prevented validation of the output. No email addresses, subdomains or host counts are claimed without verifiable output.

Keep signed authorization, credentials, tokens, private keys and unredacted network details out of the public repository.
