## Evidence handling

Store only screenshots and notes that are safe to publish. Do not commit recovered passwords, PDF hashes, password lists containing private data, credentials, tokens, or the locked source PDFs. Redact personal information and any unrelated system details before uploading evidence.

All testing must remain within the files and systems supplied for the authorised training exercise. The Mediroza module must not be tested against a live hospital service or real patient data.
