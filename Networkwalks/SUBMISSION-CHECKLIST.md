# Networkwalks — Submission Checklist

Use the official internship instructions as the source of truth; this checklist is a helper, not a replacement for them.

## Lab quality
- [ ] Every claimed result was actually verified.
- [ ] Commands and outputs correspond to the described environment.
- [ ] Screenshots are readable and relevant.
- [ ] Evidence filenames are referenced in the report.
- [ ] Troubleshooting describes real issues and verified fixes.
- [ ] No secrets, tokens, passwords, private personal data, or unrelated traffic are exposed.

## GitHub quality
- [ ] Root README explains the repository and folder structure.
- [ ] Each completed task has a focused README/report.
- [ ] Unfinished sections are clearly marked as in progress or planned.
- [ ] No VM disk images, credentials, or sensitive raw captures are committed.
- [ ] Repository visibility matches the internship's sharing rules.

## External submission
- [ ] Re-check the official submission form and deadline from the internship brief.
- [ ] Submit the correct repository URL.
- [ ] Follow any required LinkedIn tagging/posting rules only if permitted.
- [ ] Keep private IP details, credentials, and sensitive evidence out of public posts.
