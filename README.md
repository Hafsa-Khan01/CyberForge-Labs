## Repository principles
- Record only work actually performed and results actually observed.
- Remove passwords, tokens, personal data, and unnecessary network details from evidence.
- Use security tools only against systems and networks explicitly authorized for testing.
- Do not upload VM images, sensitive packet captures, or credentials.
- Evidence folders contain placeholders until verified screenshots are added.

## Suggested lab report format
1. Objective
2. Scope and authorization
3. Environment and tools
4. Procedure
5. Observations and results
6. Troubleshooting
7. Evidence
8. Lessons learned / next steps

**Status:** This is a portfolio scaffold. Mark individual labs complete only after reviewing their evidence and results.
