## Evidence and documentation principles

- Keep each programme's work in its own directory; do not mix unrelated internship deliverables.
- Preserve original screenshots, reports, notes and supporting files. Prefer adding an index or README over moving established files.
- Distinguish completed work, attempted work, planned work and reference material.
- Report only results supported by the available output or evidence.
- Use descriptive filenames and link evidence from the relevant report or index.
- Review screenshots, logs and captures for credentials, tokens, personal information and sensitive network details before publishing.
- Do not commit private keys, VM disk images, saved-state files or unreviewed packet captures.
- Perform testing only on systems and networks owned by you or explicitly authorised for assessment.
